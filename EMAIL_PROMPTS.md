# Email prompts

Sign in at `/login`, complete `/account`, reload the extension, then use these prompts from `/`.

## Profile and draft prompts

- Draft a professional leave request to `manager@example.com` for Friday 23 October because of a family function. Use my saved full name.
- Draft an email to `client@example.com` asking for the project requirements. Include my saved mobile number in the signature.
- Draft a follow-up email to `client@example.com` about the website proposal we discussed.
- Draft a thank-you email to `interviewer@example.com` after my interview for the frontend developer role.
- Open a Gmail draft to `owner@example.com` asking about a portfolio project collaboration.

## Search and reading prompts

- Search Gmail for messages from `client@example.com`.
- Search Gmail for unread messages with the subject containing `project`.
- Find emails from the last seven days with attachments.
- Read the first email from the latest Gmail search results.
- List the attachments on the currently open email.
- Open the first attachment from the current email.

## Reply and forwarding prompts

- Reply to the first search result and say that I will review the requirements today.
- Forward the first search result to `reviewer@example.com` with a short explanation.
- Draft a reply using my saved first name and full name in the signature.

## Mail management prompts

- Archive the first search result.
- Mark the first search result as read.
- Add the `Project` label to the first search result.
- Remove the `Inbox` label from the first search result.
- Delete the first search result. Ask for approval before doing it.

## Sending prompts

- Send the current Gmail draft after I review it.
- Do not send the current draft yet.

The assistant must ask for approval before sending or deleting. It must never invent a recipient, date, reason, or profile value. Search/read/reply/archive/delete/label tools are available only after authentication; draft creation remains available to public visitors when the extension is installed.
