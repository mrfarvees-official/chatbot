A public portfolio assistant that answers questions using a Supabase-powered RAG knowledge base.

- Admin document ingestion
- Hybrid vector and full-text retrieval
- Supabase authentication
- Optional browser automation

### Site Agent Extension

A Chrome extension that allows the chatbot to perform approved browser actions.

Supported workflows include:

- Opening Gmail drafts
- Searching Gmail
- Reading emails
- Replying and forwarding
- Archiving and deleting emails
- Managing labels
- Listing and opening attachments
- Calendar draft creation
- Google Meet actions

Sensitive actions require explicit user approval.
